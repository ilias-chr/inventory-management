Data Flow — Filter Change

🖱
User Input
FilterBar.vue dropdown selection
⚙️
Composable
useFilters ref updates (selectedLocation)
👁
View Watch
View detects change, calls loadData()
📡
API Call
api.js builds URLSearchParams, Axios GET
🔍
Backend Filter
apply_filters() on in-memory JSON data
✅
State Update
Reactive ref updated, computed properties recalculate
🖼
Re-render
Vue v-for re-renders filtered rows
